## Purpose

提供管理后台：用户管理（启用 / 禁用 / 重置密码）、基础数据管理（航司 / 机场 / 机型 / 渠道 CRUD）、商家放票（创建 / 更新航班）。

## ADDED Requirements

### Requirement: 用户管理页
管理后台用户管理页 SHALL 展示用户列表（可筛选），并支持启用 / 禁用账号、重置密码。仅管理员可访问（路由守卫 + 后端 403 兜底）。

#### Scenario: 查看与筛选用户
- **WHEN** 管理员进入用户管理页
- **THEN** 页面展示用户列表，可按用户名 / 角色 / 状态筛选

#### Scenario: 禁用 / 启用账号
- **WHEN** 管理员对某用户执行禁用 / 启用
- **THEN** 页面确认后更新该用户状态；目标为当前登录管理员时后端 400 并提示

#### Scenario: 重置密码
- **WHEN** 管理员对某用户执行重置密码
- **THEN** 页面提示成功，该用户可用新密码登录

### Requirement: 基础数据管理页
基础数据页 SHALL 提供航司 / 机场 / 机型 / 渠道四类数据的增删查改。删除被引用数据时展示后端拒绝提示。仅管理员可写。

#### Scenario: 维护航司
- **WHEN** 管理员在航司页新增 / 编辑 / 删除航司
- **THEN** 页面按后端结果更新列表；重名 / 被引用删除时展示对应提示

#### Scenario: 维护机场 / 机型 / 渠道
- **WHEN** 管理员维护机场（含地区）、机型（含舱位与重量校验）、渠道
- **THEN** 页面按后端结果更新；校验失败时展示错误

### Requirement: 放票管理页
放票页 SHALL 提供创建航班表单（含三舱余票与三舱票价）与航班列表编辑。仅商家或管理员可访问。

#### Scenario: 创建航班
- **WHEN** 商家 / 管理员填写航班信息（含三舱价格与余票）并提交
- **THEN** 航班创建成功并出现在航班列表；后端校验失败时展示错误

#### Scenario: 更新航班
- **WHEN** 商家 / 管理员编辑航班的运行字段（时间 / 三舱余票 / 三舱票价 / 价格 / 状态）
- **THEN** 页面展示更新后的航班信息
