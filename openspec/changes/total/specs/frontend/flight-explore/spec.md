## Purpose

提供航班搜索、列表、详情与实时轨迹页面：用户按条件找航班、查看各舱价格与余票、跟踪飞行位置。

## ADDED Requirements

### Requirement: 航班搜索页
搜索页 SHALL 提供出发地 / 到达地 / 出发日期 / 价格区间等筛选表单与"搜索"、"重置"按钮，结果以卡片列表展示（航班号、出发到达时间、起落地区、航司、各舱价格、起价与余票）。重置按钮清空全部筛选条件并重新搜索。空结果显示空状态占位。

#### Scenario: 搜索航班
- **WHEN** 用户输入筛选条件并点击搜索
- **THEN** 页面展示匹配的航班卡片列表，每张卡片含航班号、时间、起落地区、起价与各舱价格

#### Scenario: 重置筛选
- **WHEN** 用户点击"重置"按钮
- **THEN** 全部筛选条件被清空，页面展示重新搜索后的航班列表

#### Scenario: 空结果
- **WHEN** 无匹配航班
- **THEN** 页面展示空状态占位与"换个条件试试"提示

### Requirement: 航班详情页
详情页 SHALL 展示航班完整信息（时间 / 起落 / 机型 / 登机口 / 距离 / 时长 / 三舱价格与余票），并提供进入订票的入口（选舱下单）。

#### Scenario: 查看详情
- **WHEN** 用户点击某航班卡片
- **THEN** 页面展示该航班完整信息与三舱价格、余票，并提供订票入口

### Requirement: 实时轨迹页
轨迹页 SHALL 提供按航班查询实时位置的功能，展示高度、速度、纬度、经度、剩余距离、剩余时间与采集时间。无轨迹时展示空状态。

#### Scenario: 查看轨迹
- **WHEN** 用户在轨迹页输入航班并查询，该航班有轨迹记录
- **THEN** 页面展示高度、速度、经纬度、剩余距离 / 时间与采集时间

#### Scenario: 无轨迹
- **WHEN** 查询的航班没有轨迹记录
- **THEN** 页面展示空状态提示
