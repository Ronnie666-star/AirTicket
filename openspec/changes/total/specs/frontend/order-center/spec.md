## Purpose

提供我的订单列表、详情与操作（支付 / 取消 / 退订 / 改签 / 核销），按角色展示可用操作。

## ADDED Requirements

### Requirement: 订单列表
订单列表页 SHALL 展示当前登录用户自己的订单，支持按订单状态 / 支付状态 / 航司 / 时间筛选。每单展示航班号、起落地区、航司、舱级、金额、状态与关键时间，点击进入详情。状态 / 支付状态下拉均含"全部"选项（默认选中，即不过滤）。

#### Scenario: 查看订单列表
- **WHEN** 用户进入我的订单页
- **THEN** 页面展示该用户订单列表，含航班、舱级、金额、状态

#### Scenario: 筛选订单
- **WHEN** 用户按订单状态 / 支付状态 / 航司筛选
- **THEN** 列表仅展示满足条件的订单

#### Scenario: 选择"全部"筛选
- **WHEN** 用户在订单状态或支付状态下拉选择"全部"
- **THEN** 列表不按该维度过滤，展示全部订单

### Requirement: 订单详情与操作
详情页 SHALL 展示订单完整时间线与操作按钮，按订单状态与角色显示可用操作：待支付 → 去支付 / 取消；已出票 → 退订 / 改签（旅客可自助改签，商家可见核销）；支付中 → 支付处理中提示；航班已取消 → 展示"已取消并全额退款，可改签"提示条并提供改签入口。

#### Scenario: 待支付订单操作
- **WHEN** 用户打开待支付订单详情
- **THEN** 页面展示"去支付"与"取消订单"操作

#### Scenario: 已出票订单操作
- **WHEN** 用户打开已出票订单详情
- **THEN** 旅客看到"退订 / 改签"；商家看到"核销 / 退订 / 改签"

#### Scenario: 退订成功
- **WHEN** 用户对已支付订单执行退订
- **THEN** 页面提示退订成功并展示退款金额（总价 − 退票费），订单状态更新

#### Scenario: 航班已取消订单展示
- **WHEN** 用户打开因航班取消而置"已取消 + 已退款"的订单详情
- **THEN** 页面展示"该航班已取消并全额退款，可改签"提示条，并提供改签操作

### Requirement: 改签交互
改签 SHALL 提供选择新航班的能力：用户从可改签航班列表选择（同航线、未起飞、未取消、有对应舱级余票），确认后展示应补 / 应退金额并提交。旅客可自助改签本人订单（已出票，或航班已取消且已退款的订单）。

#### Scenario: 选择改签航班
- **WHEN** 用户对已出票订单发起改签
- **THEN** 页面展示可改签航班（同航线、未起飞、该舱有余票，不含当前航班），选择后展示补差 / 退款金额并提交

#### Scenario: 航班取消订单改签
- **WHEN** 用户对因航班取消而退款的订单发起改签
- **THEN** 页面展示同航线、未起飞、该舱有余票的候选航班，改签成功后订单置"已改签"
