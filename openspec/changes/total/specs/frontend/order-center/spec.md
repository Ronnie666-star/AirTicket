## Purpose

提供我的订单列表、详情与操作（支付 / 取消 / 退订 / 改签 / 核销），按角色展示可用操作。

## ADDED Requirements

### Requirement: 订单列表
订单列表页 SHALL 展示当前登录用户自己的订单，支持按状态 / 支付状态 / 航司 / 时间筛选。每单展示航班号、起落地区、航司、舱级、金额、状态与关键时间，点击进入详情。

#### Scenario: 查看订单列表
- **WHEN** 用户进入我的订单页
- **THEN** 页面展示该用户订单列表，含航班、舱级、金额、状态

#### Scenario: 筛选订单
- **WHEN** 用户按订单状态 / 支付状态 / 航司筛选
- **THEN** 列表仅展示满足条件的订单

### Requirement: 订单详情与操作
详情页 SHALL 展示订单完整时间线与操作按钮，按订单状态与角色显示可用操作：待支付 → 去支付 / 取消；已出票 → 退订 / 改签（商家可见核销）；支付中 → 支付处理中提示。

#### Scenario: 待支付订单操作
- **WHEN** 用户打开待支付订单详情
- **THEN** 页面展示"去支付"与"取消订单"操作

#### Scenario: 已出票订单操作
- **WHEN** 用户打开已出票订单详情
- **THEN** 旅客看到"退订 / 改签"；商家看到"核销 / 退订 / 改签"

#### Scenario: 退订成功
- **WHEN** 用户对已支付订单执行退订
- **THEN** 页面提示退订成功并展示退款金额（总价 − 退票费），订单状态更新

### Requirement: 改签交互
改签 SHALL 提供选择新航班的能力：用户从可改签航班列表选择（同航司、未起飞、有对应舱级余票），确认后展示应补 / 应退金额并提交。

#### Scenario: 选择改签航班
- **WHEN** 用户对已出票订单发起改签
- **THEN** 页面展示可改签航班（同航司、未起飞），选择后展示补差 / 退款金额并提交
